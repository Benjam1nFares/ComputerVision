# Hand Tracking en Tiempo Real con MediaPipe Tasks 👁️🖐️

Proyecto inicial de Visión por Computadora (Computer Vision) para detectar y vectorizar los 21 landmarks de la mano utilizando el feed de la webcam.

## 🛠️ Tecnologías utilizadas
* **Python 3.x**
* **OpenCV** (Procesamiento de video y renderizado de gráficos)
* **MediaPipe** (Nueva API de Google Tasks para predicción de landmarks)

## 🚀 Cómo ejecutarlo
1. Cloná este repositorio.
2. Descargá el modelo oficial [hand_landmarker.task](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task) y guardalo en la raíz del proyecto.
3. Instalá las dependencias: `pip install opencv-python mediapipe`
4. Ejecutá el script principal.
